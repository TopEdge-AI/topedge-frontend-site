**Recommendation: monitor, do not disavow.** Per the brief's own rule, disavow
only on a manual action or a clear large-scale toxic pattern. Check GSC for a
manual action once GSC is connected (which is blocker #1 anyway). Re-pull this
profile monthly and watch whether spam score climbs.

## 5. Tactics, ranked by effort-to-payoff for a low-authority Indian D2C SaaS

**Tier 1 — do first (free, legitimate, also fixes the entity problem in §1)**
1. **Own-listing hygiene.** G2 (claim + correct the inaccurate "technology
   company specializing in AI solutions" description), Crunchbase,
   AlternativeTo, Product Hunt, SaaSworthy, Capterra/GetApp, Shopify Partner
   directory. Each is a real link *and* third-party corroboration of the brand
   entity, which is the §1 blocker. **Use identical name, one-sentence
   definition and description everywhere.**
2. **Shopify App Store reviews.** Not a link, but it gates everything in the
   Shopify ecosystem including #4 below. Five merchants already reviewed on
   Trustpilot; three are named on-site with live stores.
3. **Listicle inclusion.** The ~12 "best WhatsApp tools / RTO tools /
   Wati alternatives" pages found holding page 1 (listed in
   `05-geo-manual-protocol.md`). Pitch a factual inclusion with an accurate
   blurb. This is the single highest-leverage off-site action because the same
   pages feed AI Overviews (§2).

**Tier 2 — build the assets**
4. **Shopify ecosystem presence** → the `shopify.com` link in §4.
5. **Linkable assets we already partly have.** `/tools` already ranks #3 for a
   brand-plus-category query, which is evidence the free-tools approach works
   here. Extend: RTO cost calculator, WhatsApp template library (AiSensy runs
   74 template pages at 1,863–2,130 words — the pattern worth emulating), the
   Cloud-API-for-Shopify setup guide.
6. **Case studies as their own URLs.** Interakt 71, AiSensy 65, Gallabox 62,
   LimeChat 47, DoubleTick 34. **We have 0** — one `/customers` page carries
   everything. Three real case studies are available today from merchants
   already quoted on-site, with no invention required.
7. **Original data.** An Indian D2C cart-abandonment / RTO benchmark from
   aggregated anonymised product data — **only** if merchant terms and privacy
   allow and the numbers are real. This is the strongest link tactic in the
   category but it is also the one most easily faked, so it must be genuinely
   sourced with a published methodology.

**Tier 3 — slower**
8. Digital PR to Inc42 / YourStory / Entrackr with the §7 data study or a
   founder POV, never "please link to us".
9. Founder-led LinkedIn/X and podcasts. Disclose sponsorship with
   `rel="sponsored"` where it applies.
10. Unlinked brand mentions → polite link requests. Note this is weak for us
    right now precisely because of §1: there are few mentions to convert.
11. Reddit r/shopify holds #8 for `whatsapp cart recovery shopify`. Answer real
    questions, disclose affiliation, link only when genuinely relevant.
    **Never astroturf** — Google filters inauthentic mentions and it would
    damage the brand we are trying to establish.

## 6. Quality gate (reject anything failing any line)
Topical relevance · real audience · editorial or genuinely useful context ·
not for sale · not part of a scheme · correct attribute
(`nofollow`/`sponsored`/`ugc`). **No** purchased links, PBNs, link farms,
large-scale exchanges, comment spam, expired-domain tricks or "DR boost"
packages.
